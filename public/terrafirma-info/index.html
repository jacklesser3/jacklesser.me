Arrival

If you registered, show your confirmation to a host at the entrance. If you need help or arrive without a booking, a host can offer a time to come back.

Machine demo

Watch an operator and engineer from the rail or on the stage screen. Ask a host whether coached turns are available that day. If you have a turn, wait for the host to call you over. You can also try the practice controls, which run a simulator.
